# Licencia pendiente de decisión

Este repositorio **no incluye un archivo `LICENSE`** porque el titular de los
derechos no ha elegido todavía una licencia. No se inventa una licencia nueva ni
se asume una por defecto: mientras no exista una decisión explícita, el código
queda bajo el régimen legal por defecto del titular (todos los derechos
reservados), lo que impide su reutilización, modificación o redistribución por
terceros.

## Decisión necesaria

El propietario debe elegir y añadir un archivo `LICENSE` con el texto completo
de una licencia OSI aprobada. Opciones habituales para una herramienta local:

| Licencia | Cuándo tiene sentido |
| --- | --- |
| MIT | Se permite reutilización amplia con atribución y sin garantía. |
| Apache-2.0 | Como MIT, con concesión explícita de patentes. |
| GPL-3.0 | Se exige que las obras derivadas sigan siendo libres. |
| Propietaria | No se permite reutilización; solo se distribuye el binario. |

Una vez añadido `LICENSE`, hay que actualizar este archivo (o eliminarlo), la
sección de licencia de `README.md` y el paquete de distribución del CI.
